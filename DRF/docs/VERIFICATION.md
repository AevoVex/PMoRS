## Как воспроизвести

Из `D:\Dev\PMoRS\DRF`:

```powershell
..\.venv-drf\Scripts\python.exe scripts\verify.py
..\.venv-drf\Scripts\python.exe scripts\smoke_http.py
```

При установке по README в `.venv` замените путь к интерпретатору на `.\.venv\Scripts\python.exe`.

`verify.py` последовательно выполняет системные проверки, проверку миграций и три набора тестов. Любой сбой завершает скрипт с ненулевым кодом. [Сохранённый вывод](verification.txt).

`smoke_http.py` создаёт временные SQLite-базы, применяет миграции, дважды выполняет `seed_demo`, поднимает локальные WSGI-серверы на свободных портах и отправляет настоящие HTTP-запросы через `urllib`. После проверки серверы завершаются через канал stdin, временные базы удаляются. Рабочие демонстрационные базы не затрагиваются. [Сохранённый вывод HTTP-проверки](http-smoke.txt).

Промежуточный Token-режим дополнительно проверяется так (из `kittygram`, с активированным окружением):

```powershell
$env:KITTYGRAM_LESSON_TOKEN = '1'
python manage.py test lessons --settings=config.lesson_settings --verbosity 2
Remove-Item Env:KITTYGRAM_LESSON_TOKEN
```

Это повторный запуск тех же десяти тестов с включённой авторизацией, а не ещё десять разных тестов.

## Что означает успешная проверка

Проверены реальные Django-модели, миграции, ограничения SQLite, сериализаторы, обработчики и Token/JWT-аутентификация. HTTP smoke дополнительно подтверждает работу приложения за пределами встроенного тестового клиента. Для картинки создан небольшой настоящий PNG и выполнена multipart-загрузка.

Тесты проверяют отказ при подмене автора/владельца, доступ другого пользователя, невозможность обновить уникальное имя на занятое, границы возраста, неполный PATCH, вложенные достижения, отсутствие частичной записи при невалидном массиве, ограничения доступных HTTP-методов.

Публикация в интернете и ручная сессия Postman не проводились. Нагрузка, конкурентная работа в production-БД и внешний автопроверяющий набор преподавателя не проверялись. Успех локальных проверок не выдаётся за оценку или сдачу преподавателю.
